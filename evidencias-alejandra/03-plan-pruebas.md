\## Objetivo

Verificar que el sistema SIGMA-LAB UNI cumpla con todos los requerimientos funcionales y no funcionales definidos durante la fase de analisis.



\## Alcance

Las pruebas cubren todos los modulos del sistema:

\- Autenticacion

\- Dashboard

\- Incidentes

\- Activos

\- Mantenimientos

\- Laboratorios

\- Indicadores

\- Notificaciones

\- Perfil de usuario

\- Gestion de usuarios



\## Tipos de pruebas realizadas



\### Pruebas funcionales

Verifican que cada funcionalidad trabaje segun lo especificado.



\### Pruebas de integracion

Verifican que el frontend, backend y base de datos se comuniquen correctamente.



\### Pruebas de seguridad

Verifican que los mecanismos de autenticacion y autorizacion funcionen.



\### Pruebas de navegacion

Verifican que los usuarios puedan moverse entre paginas correctamente.



\### Pruebas de usabilidad

Verifican que la interfaz sea clara e intuitiva para el usuario.
